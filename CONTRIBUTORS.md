# Contributors

EPay is built by everyone who files an issue, reviews a pull request, writes a
test, or fixes a typo. Thank you.

This file lists people and automations who have contributed to the project.
It is updated by hand when a pull request is merged; if we have missed you,
open a pull request that adds your name — that counts as a contribution too.

## How to be listed

1. Land a pull request that is merged to `main`.
2. Add a row to the **Contributors** table above in the same pull request, or in
   a follow-up — either is fine.

We do not rank contributions by size. A documentation fix that saves a partner
an hour is worth as much as a new endpoint.
